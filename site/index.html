Ce que Slide-up simplifie

PowerPoint entre dans la régie, proprement.

Pas de recadrage d’écran, pas de moniteur virtuel, pas de détour par une carte de capture. La présentation devient directement une source réseau exploitable.

01

Transparence réelle

Exportez les formes et le texte en PNG alpha pour créer des titrages, overlays et lower thirds sans fond PowerPoint.

02

NDI intégré

La runtime d’envoi est incluse. Aucun NDI Tools n’est nécessaire sur l’ordinateur qui diffuse la présentation.

03

Contrôle de présentation

Naviguez avec les raccourcis clavier ou votre pointeur sans fil, tout en gardant les commandes noir, blanc et transparent.

Questions fréquentes

Avant de passer à l’antenne.

Faut-il installer NDI Tools ?

Non sur le poste qui envoie les slides : la runtime NDI est incluse dans Slide-up. Le poste de réception doit disposer d’un logiciel compatible NDI, comme OBS avec le plugin adapté, vMix ou NDI Studio Monitor.

Microsoft PowerPoint est-il obligatoire ?

Oui. Slide-up utilise l’automatisation PowerPoint sous Windows pour conserver la meilleure fidélité possible lors de l’export.

Peut-on diffuser une diapositive sans fond ?

Oui. Le mode sans fond exporte les formes et le texte en PNG avec transparence, pratique pour les titres et habillages vidéo.

Le projet est-il open source ?

Le code source de Slide-up est publié sous licence MIT. Les composants tiers, dont la runtime NDI, conservent leurs licences respectives.
